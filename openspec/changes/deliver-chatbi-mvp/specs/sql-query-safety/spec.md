# Spec Delta

## Purpose

该能力在模型输出与数据库执行之间建立强制只读安全边界，使演示系统即使收到恶意问题或错误 SQL，也不会修改数据或访问未授权对象。

## ADDED Requirements

### Requirement: 仅允许单条只读查询
系统 MUST 仅允许一条以 `SELECT` 或只读 `WITH ... SELECT` 为根语句的 SQL，并 MUST 拒绝多语句、注释绕过、数据定义、数据修改、权限控制、事务控制及存储过程调用。

#### Scenario: 执行合法只读查询
- **WHEN** 模型生成一条语法有效的 `SELECT` 查询
- **THEN** 安全层允许该查询进入后续约束处理

#### Scenario: 拒绝数据修改
- **WHEN** SQL 包含 `INSERT`、`UPDATE`、`DELETE`、`DROP`、`ALTER`、`TRUNCATE` 或其他非只读根语句
- **THEN** 系统返回安全拒绝错误且数据库不会收到该 SQL

#### Scenario: 拒绝多语句
- **WHEN** SQL 在一个请求中包含两条或更多可执行语句
- **THEN** 系统返回安全拒绝错误且不执行其中任何语句

### Requirement: 限制可访问数据对象
系统 MUST 只允许查询配置白名单中的业务表与允许的字段，并 SHALL 拒绝访问系统库、元数据表、未知表以及被标记为敏感的字段。

#### Scenario: 查询白名单业务表
- **WHEN** SQL 只引用演示业务 Schema 中允许的表和字段
- **THEN** 安全层允许查询继续执行

#### Scenario: 查询未授权对象
- **WHEN** SQL 引用白名单外的表、系统 Schema 或敏感字段
- **THEN** 系统返回安全拒绝错误并记录被拒绝的对象类型

### Requirement: 强制结果行数上限
系统 SHALL 为未指定限制或限制超过配置上限的明细查询施加服务端最大行数限制，同时保持聚合查询的业务语义。

#### Scenario: 明细查询未指定 LIMIT
- **WHEN** SQL 返回明细行且没有 `LIMIT`
- **THEN** 系统在执行前施加配置的最大行数限制

#### Scenario: 明细查询请求过大 LIMIT
- **WHEN** SQL 指定的 `LIMIT` 超过服务端上限
- **THEN** 系统将有效限制收敛到服务端上限

### Requirement: 限制查询执行时间
系统 MUST 为每次数据库查询设置超时，并在超时后终止或取消查询、释放连接并返回稳定的超时错误。

#### Scenario: 查询在时限内完成
- **WHEN** 数据库查询在配置的时限内返回
- **THEN** 系统正常返回查询结果并记录执行耗时

#### Scenario: 查询超时
- **WHEN** 数据库查询超过配置时限
- **THEN** 系统返回查询超时错误且连接可被后续请求安全复用或丢弃

### Requirement: 使用最小权限数据库身份
运行时 MUST 使用仅能读取演示业务对象的数据库身份；系统启动检查 SHALL 在账号不满足只读假设时给出警告或失败状态。

#### Scenario: 只读账号配置正确
- **WHEN** 健康检查使用配置的数据库身份验证连接和只读查询
- **THEN** 数据库依赖状态报告为可用

#### Scenario: 数据库身份不可用
- **WHEN** 凭据错误、连接失败或账号无法读取必需业务表
- **THEN** 健康检查报告数据库不可用且查询端点不得伪装成功

### Requirement: 安全日志不得泄露机密
系统 SHALL 记录请求标识、安全决策、耗时和错误分类，但 MUST 对数据库密码、API Key、连接串以及敏感结果值进行隐藏或脱敏。

#### Scenario: 安全拒绝被记录
- **WHEN** 一条 SQL 被安全策略拒绝
- **THEN** 日志包含请求标识和拒绝原因分类，但不包含任何密钥或密码
