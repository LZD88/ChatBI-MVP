# P2 实施与验收记录

日期：2026-11-14。项目：`D:\学习资料\ChatBI`。

## 完成范围

### 图表可视化

- 查询 API 返回后端生成的 `visualization_spec`，简单查询及复杂查询成功步骤都可生成图表。
- 支持 KPI、折线、柱状、堆叠、饼图及明确变动语义的瀑布图，前端使用本地 Apache ECharts 5.6.0，支持 PNG 导出。
- 不允许模型提供 JavaScript；金额和比例分轴、编号维度识别、空值、重复粒度、行数上限和截断范围均有处理。
- 复杂步骤的 Decimal JSON 字符串仅按已验证的数值输出契约转换，原证据不变；瀑布图使用累计起止点，能处理负数和跨零变化。

### 指标管理

- 新页面 `/metrics`：搜索、草稿、版本追溯、提交审核、发布、驳回、放弃草稿、废弃、上下游血缘及操作记录。
- SQLite 管理库首次导入 61 个治理指标，保留责任人、变更说明、发布时间和审核标签；不增加业务 MySQL 账号写权限。
- 发布前检查重名、别名冲突、未知依赖和循环；废弃检查下游；事务避免并发重复版本和发布部分成功。
- 新查询使用同一目录快照，Chroma 内容 Hash 刷新支持指标数量不变时的定义升级。主页生效指标数量动态更新。
- 本地单用户审批，操作人是审计标签；没有将其声明为多人认证审批。发布立即生效；多进程索引刷新协调和预约发布暂不支持。

### 评测与 CI

- `ci.yml`：push/PR 后端测试、MyPy、所有 Node 测试、基础密钥扫描及空白检查。
- `integration.yml`：每日隔离 MySQL/Chroma 联测；手动勾选真实模型评测，读取 GitHub Secrets；集成用例若跳过则失败。
- 三项复杂查询基准覆盖低毛利筛选后成本复核、预算超支和设备维护成本排名。
- 真实模型发布脚本检查简单 SQL 准确率、复杂计划/步骤/结果/证据/建议结构/依赖/总结模型成功率，记录耗时和可用 Token usage；不满足阈值退出失败。
- 证据与建议结构通过不等于真实业务有效，报告保留人工业务评审状态。缺失 Token 统计显式标记不完整。
